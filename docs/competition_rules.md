# Competition Restrictions Overview

- **외부 데이터 금지**: 대회에서 제공하지 않은 모든 외부 데이터셋 활용 불가.
- **평가 데이터 사용 제한**: 평가 데이터 분석은 가능하지만, 학습/튜닝에 직접 사용하거나 의존하는 행위 금지.
- **사전 학습 가중치**: 공개적으로 이용 가능한 프리트레인 가중치(예: ImageNet)는 사용 가능.
- **OCR/LLM 사용 제한**: 상용 OCR, LLM 모델 사용 금지 (무료로 공개된 모델만 활용 가능).
- **API 활용**: 무료 API만 사용 가능.
- **제출 제한**: 팀 기준 하루 최대 12회 제출, 한국 시간 자정에 초기화.
- **재현성 요구**: 상위권 진입 시 코드/데이터 전체를 제출해 재현 가능성을 증명해야 하며, 미제공 시 실격될 수 있음.
- **라이선스 유의사항**: 데이터는 교육 내에서만 활용 가능하며 외부에 노출 금지. 베이스라인 코드 수정본은 공개 가능하나 원본 코드는 그대로 공개하지 말 것.

필요 시 이 문서를 팀 내부 규칙 및 실험 정책으로 확장해 주세요.
