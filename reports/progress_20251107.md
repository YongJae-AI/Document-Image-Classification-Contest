## Additional Notes
- **Augraphy sample size**: Current `configs/offline_aug.yaml` sets `target_total = 8000`, so with 1593 originals we generate ~6400 augmented images (≈50% of target_total per class). We shortened the run intentionally to keep CPU time reasonable and avoid storage bloat; the pipeline remains sequential to minimize OOM risk. Increasing `target_total` later will simply raise the repeats per image.

- **Augraphy v2 delta**: The refreshed pipeline builds on the above by layering ColorPaper + Moire/Pattern/Voronoi textures, randomized BleedThrough (with dynamic alpha/offset), ±90° orientation snaps, and a lighter `repeats_min_per_image=1` so we only add ≈2k new samples instead of recreating the full 6k. All stages still run on CPU sequentially, so GPU memory stays untouched.

- **Augraphy transformations used**:
  - Ink phase (doc/card): `Markup` (underline/strike/highlight), `Scribbles`, `InkBleed`, plus the new randomized `BleedThrough` (alpha/offset picked per sample).
  - Paper phase: `ColorPaper` tuned per profile + `OneOf(Moire, PatternGenerator, Voronoi)` and `OneOf(NoiseTexturize, BrightnessTexturize)` for texture and color drift.
  - Post phase: Folding, `OneOf(LightingGradient/LowLightNoise/ReflectedLight/ShadowCast)`, `OneOf` geometric blocks (small jitter vs ±90° snap), `Rescale`, `Jpeg`.
  - Non-doc profiles keep only light color paper + lighting/geometry so that rigid objects (dashboard/plate) are not over-perturbed.

- **Why Albumentations “reference” pipeline helped**:
  - Adds aggressive spatial variety (`Quarter/Half/Divide` crops, `ShiftScaleRotate`, `Affine` up to ×1.6, `OpticalDistortion`), plus random flips and re-padding before resizing.
  - This matches the evaluation-set distortions (cropped sections, rotated/shifted pages) that Augraphy alone didn’t fully cover. As a result Fold0 CV improved from 0.9790 → 0.9834 despite the same offline dataset.

These observations will guide the next iteration where we incorporate the full reference pipeline (strong Augraphy + Albumentations mix) and compare results again.
